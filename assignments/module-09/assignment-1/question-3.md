# Module 9 — Assignment 1 — Question 3

## Question / 题目 3

### English

What four types of information should you record in your agency’s database when prospecting or responding to enquiries? Select all that apply.

### 中文题意

在 prospecting 或回应 enquiry 时，agency database 应记录哪四类信息？选择四个正确选项。

## Answer / 作答

### Answer in English / 英文答案草稿

Select these four options:

1. **Purpose of the enquiry**
2. **Number of calls or appraisals made**
3. **Name and contact details**
4. **Preferred contact method or frequency**

### 中文解析

这四项都与了解 enquiry、管理联系人和衡量 prospecting activity 直接相关。宠物名字、社交媒体账号和 front-door colour 不是本题要求的 agency prospecting database 信息。

- Workbook §4.1 要求保护 contact information、privacy 和 confidentiality；§4.6 反向说明 social media likes 不应作为 prospecting database 记录。
