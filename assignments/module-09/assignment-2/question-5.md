## Answer / 作答

### Answer in English / 英文答案草稿

| Description | Answer |
|---|---|
| Can only be completed by a licensed valuer | **Valuation** |
| Provides a legal value used in court, lending, or taxation | **Valuation** |
| An estimate of market price provided by a sales representative or agent | **Appraisal** |
| Typically used to set a sale or rental price | **Appraisal** |
| Based on recent sales, market trends, and local knowledge | **Appraisal** |
| Regulated under professional valuation standards | **Valuation** |

### 中文解析

前三类 distinction：appraisal 是为潜在 sale/listing 的市场估计，由 agent 或 sales representative 基于市场资料和经验制作；valuation 是用于 court、finance、tax 等正式法律用途，只能由 licensed valuer 完成并符合 valuation standards。
