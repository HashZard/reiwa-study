What must you do to verify the identity of the seller before listing a property? Select one of the following.

## Answer / 作答

### Answer in English / 英文答案草稿

**Verify the client’s identity using appropriate ID checks (e.g. 100-point ID check).**

### 中文解析

正确选项是 appropriate ID checks。对个人注册业主，Workbook 给出的具体做法是 100-point ID check；同时 Code 要求取得 Certificate of Title，并作出合理努力核验各卖方或代表卖方者的身份和授权。
