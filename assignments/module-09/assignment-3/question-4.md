# Module 9 — Assignment 3 — Question 4

## Question / 题目 4

### English

When using data from CMA platforms such as RP Data or Pricefinder, what is an important professional requirement?

Options include authorised appraisal use and accurate reporting; sharing data in marketing; requiring professional photographs; and including all data even if outdated.

### 中文题意

选择使用第三方 CMA 平台数据时的重要专业要求。

## Answer / 作答

### Answer in English / 英文答案草稿

Use the data only for authorised appraisal purposes and ensure accuracy in reporting.

### 中文解析

WB3 要求使用 current, reliable data，并遵守第三方平台的 terms of use，尤其注意不得未经许可重用于 marketing 或 public communications。
